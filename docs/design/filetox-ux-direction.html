우선 적용할 세 가지

01 · 홈의 작업 흐름

선택 → 형식 → 결과를 한곳에

선택한 파일을 계속 보여주고, 사용 가능한 형식을 먼저 제시합니다. 전체 형식은 필요할 때 펼칩니다.

02 · 원형 메뉴

현재 대상을 읽기 쉽게

6–8개 항목의 가독성을 먼저 검토하고, 방향키·Enter·Escape 조작과 선택 불가 이유를 보강합니다. 12개 설정은 보존합니다.

03 · 시각적 일관성

강조는 행동에 집중

시스템 서체와 SF Symbols를 유지합니다. 주요 버튼만 강조하고, 카드 중첩보다 간격·구분선으로 내용을 묶습니다.

레퍼런스에서 가져올 기준

Tangerine은 드래그·선택 경험, Lucian UX/UI는 상태별 점검 항목, 아이콘 자료는 의미와 스타일의 통일, Taste는 디자인 방향과 시각 검증, Impeccable은 정보 위계와 불필요한 장식 정리에 활용합니다. 웹용 효과와 폰트는 macOS에 맞게 판단합니다.

REA 조사는 메뉴가 열리고 닫히는 조건, 파일 종류별 항목 구성, 완료·실패 피드백처럼 구체적인 질문부터 시작합니다. 공개 웹 데모만으로 네이티브 구현을 단정할 수 없습니다.
