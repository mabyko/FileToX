위 버튼은 흐름만 시연합니다. 실제 시스템 설정이나 macOS 권한은 변경하지 않습니다.

표시와 확인 규칙

첫 실행→설정 열기→돌아와 확인→시작하기
나중에 선택홈으로 이동. 재실행에는 자동으로 뜨지 않고 호출 키 설정에서 다시 열 수 있습니다.
처음부터 허용됨첫 안내에서 바로 완료 화면을 보여줍니다.
허용 확인 실패대기 화면에서 설정 방법을 다시 안내합니다. 반복 팝업은 띄우지 않습니다.
허용 확인 성공같은 시트를 완료 화면으로 바꿉니다. 실제 권한을 조회한 결과로만 판단합니다.
파일 열기로 시작받은 파일을 먼저 처리하고 최초 안내는 변환 흐름 뒤로 미룹니다.

시스템 권한 안내는 비동기로 실행됩니다. 설정을 연 직후의 반환값으로 허용·거절을 결정하지 않습니다. Apple API 문서
